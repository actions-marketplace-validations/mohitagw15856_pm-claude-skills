# Week 4: Priorities and goals

## Learning outcomes

- Score competing initiatives with RICE and explain where the scores are guesses.
- Write OKRs whose key results measure outcomes, not output.
- Build a metrics framework with a north star, input metrics and guardrails.

## Skills used

- `rice-prioritisation`: RICE scoring and a ranked list.
- `okr-builder`: objectives and key results.
- `metrics-framework`: north star, inputs and guardrails.

## Case material

Five fictional Larder initiatives for next quarter, each with rough reach, impact and effort notes: the smart shopping list, a recipe-swap feature, a cheaper annual plan, a referral scheme, and fixing a slow onboarding flow. Leave one estimate deliberately vague.

## In-class exercise (60 minutes)

1. **RICE (20 min).** Run `rice-prioritisation` on the five initiatives. Then change the one vague estimate by 50% either way. Does the ranking change? Write one sentence on how confident the team should be.
2. **OKRs (20 min).** Run `okr-builder` for the quarter. Rewrite any key result that is a task ("launch X") as an outcome ("week-4 retention from 33% to 37%").
3. **Metrics (20 min).** Run `metrics-framework`. Add one guardrail the skill missed, such as support contacts per thousand users.

## Graded assignment A4: prioritised plan with OKRs and metrics (10%)

A one-page quarterly plan: the ranked initiatives with a sensitivity note, two objectives with three key results each, and the metrics framework.

**Week-specific criteria (0 to 4 each):**

| Criterion | What a 4 looks like |
|---|---|
| Honest prioritisation | The ranking states which scores are estimates and shows that the top choice survives a reasonable change in them, or says plainly that it does not. |
| Outcome key results | Every key result has a baseline and a target and could be missed; none is a task. |

## Instructor note

RICE output looks precise because it has decimals. The sensitivity step teaches more than the scoring does. If time is short, cut the metrics step, not the sensitivity step.
